# Landingpage (GitHub Pages)

Scope: `site/index.html`, the public landing page at pvanissem.github.io/hearth. Mode: Persuade.
Audience: developers using agent CLIs on a Mac. Action: copy the install command. Belief after the first viewport: "my agent, my subscription, but fenced in". Proof: real app screenshots from a neutral demo project; real sandbox rules. Constraints: German, current version (v0.2) labelled honestly, no invented numbers or testimonials, no generic SaaS look, little text.

## Direction contract

THESIS: The sandbox is a ring of stones around a fire. Agents burn bright, but only inside the ring. Refuses the category default of headline + big app screenshot + feature grid.

OWN-WORLD: Night ground (#0e0a12 to plum #2a1e2e), firelight as the only light source: crimson #c4161c, ember #ff5a1f, flame #ffa62b, ash-pink text #e9dfe6. Field stones are the component language: irregular rounded slabs with chiselled labels; sparks are the motion material. Smoke-soft gradients only as light falloff, never as decoration.

STORY: See the ring, read what it keeps out, understand that the fire in the middle is your own agent, copy one line, see the app it installs.

FIRST VIEWPORT: Full-bleed night. Left third: wordmark, headline "Dein Agent. Dein Abo. Unser Feuerring.", one line of subcopy, the glowing install command with a copy control, the fact border below it. Right two thirds: a ring of eight labelled stones (~/.ssh, ~/.zshrc, Browserdaten, Schlüssel der Cloud, übriges Home, example.com …) around a living fire whose core cycles agent names. On phones the ring sits above the copy at reduced scale.

FORM: Grounded candidate 5 of 7 (Feuerring bei Nacht). seed:d51208b3876b2c39. Signature interaction: sparks rise from the fire; any spark reaching the ring dies on a stone with the stone briefly glowing and its blocked rule shown. Motion grammar: flicker and rising sparks only, reduced-motion turns them off. Raises: numbered timed install sequence (neon sign), dense fact border (theatre poster), each stone shows its real nono rule (jacquard).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
