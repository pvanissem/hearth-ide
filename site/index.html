What stays inside the ring.

Hearth starts every agent in a nono sandbox (macOS Seatbelt). Inside the ring it works freely:

  • read and write ~/your-project
  • its own settings folder inside Hearth
  • LLM APIs, npm, PyPI, Maven
  • GitHub, GitLab and documentation

Kept outside:

  • SSH keys

  • shell configuration

  • cloud credentials

  • cookies, passwords, sessions

  • the rest of your home folder

  • every host you haven’t allowed

Allow more domains, ports and folders in the settings. API keys pass through nono as a placeholder: the agent never sees the real value.

No account, no configuration. Hearth brings the sandbox, you bring your agents.
